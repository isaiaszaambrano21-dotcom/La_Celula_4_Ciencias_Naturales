# 🧬 RED La Célula - Recurso Educativo Digital

## Proyecto Final - Multimedia II
**Tema:** Unidad 2 - La Célula  
**Nivel:** 4° Grado - Ciencias Naturales  
**Fuente:** Libro oficial MEDUCA - Panamá  

## 🚀 Características

- ✅ Sistema de autenticación (login/registro) con Supabase
- ✅ 6 actividades gamificadas interactivas
- ✅ Sistema de puntuación y calificación
- ✅ Leaderboard en tiempo real
- ✅ Sistema de badges/logros
- ✅ Seguimiento de progreso individual
- ✅ Video educativo integrado
- ✅ Audio narrativo con transcripción
- ✅ Diseño responsivo y accesible
- ✅ Evaluado bajo Modelo COdA

## 🛠️ Instalación

1. Crear proyecto en [Supabase](https://supabase.com)
2. Ejecutar `supabase-schema.sql` en el SQL Editor
3. Copiar `.env.example` a `.env` y agregar credenciales
4. Actualizar `js/config.js` con URL y Anon Key
5. Desplegar en GitHub Pages, Netlify o Vercel
